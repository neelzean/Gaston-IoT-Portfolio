##  Featured Projects

### “GESTURA”: Wearable Device for Translating and Learning Filipino Sign Language  (Capstone)
The study introduces GESTURA, a wearable glove-based device paired with an offline Android application that translates selected Filipino Sign Language (FSL) gestures into text and speech. Using **flex sensors**, an **accelerometer**, and an **ESP32 microcontroller**, the system captures hand movements and sends the data via Bluetooth to the mobile app for gesture recognition. 

###  ESP32 Flood Alert System
An IoT-based emergency system designed for disaster preparedness using **ESP32** to monitor water levels and trigger alerts.
